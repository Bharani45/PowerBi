# HR Analytics Dashboard (Power BI)

This dashboard analyzes employee attrition across departments, job roles, education, salary brackets, and more. Built using Power BI with data cleaning via Power Query and DAX for calculations.

## Features:
- Attrition Rate, Avg Salary, Avg Tenure
- Interactive Filters (Department, Gender)
- Visuals: Pie, Bar, Line Charts
- Custom UI with Glassmorphism Design

## Tools Used:
- Power BI, Power Query, DAX
